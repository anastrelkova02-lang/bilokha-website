# БIЛОKhA — поетичний архів

Персональний сайт сучасного українського поета: редакційний поетичний архів з власним типографічним знаком, окремими сторінками віршів, візуальним щоденником і мінімалістичними сторінками «Про автора» та «Контакт».

**Стек:** Next.js 15 (App Router, статична генерація) · React 19 · TypeScript · чистий CSS · шрифти Noto Serif Display, Noto Serif, Onest та IBM Plex Mono (повна підтримка української кирилиці, самохостинг через `@fontsource`, лише прямі накреслення — без курсиву).

---

## Структура

```
app/                    сторінки (маршрути)
  page.tsx              Головна
  poeziia/              Поезія — архів і сторінки віршів (/poeziia/[slug])
  arkhiv/               Візуальний архів
  pro-avtora/           Про автора
  kontakt/              Контакт
  globals.css           уся візуальна система (кольори, типографіка, макети)
  icon.svg, apple-icon.png, opengraph-image.png   іконки та превʼю для соцмереж
components/             Wordmark (логотип), Header, Footer, Photo, PoemIndex, Diary, Reveal, SectionHead
content/                ← ВЕСЬ ЗМІСТ САЙТУ ТУТ
  poems.ts              вірші
  photos.ts             фотографії та порядок кадрів в архіві
  site.ts               назва, опис, пошта, Instagram, біографія
brand/                  логотип: SVG/PNG-файли + інструмент генерації (brand/tools)
lib/wordmark.ts         дані логотипа для сайту (згенеровані)
```

## Запуск локально

Потрібен Node.js 18.18+.

```bash
git clone https://github.com/<ваш-акаунт>/bilokha-website.git
cd bilokha-website
npm install
npm run dev        # http://localhost:3000
npm run build      # перевірка продакшн-збірки
```

## Як оновлювати зміст

### Додати вірш
Відкрийте `content/poems.ts`, скопіюйте один обʼєкт і вставте в кінець масиву:

```ts
{
  slug: 'nova-nazva',          // адреса: /poeziia/nova-nazva
  title: 'НОВА НАЗВА',
  layout: 'classic',           // classic | split | margin | vertical | cover
  photo: 'fog',                // ключ з content/photos.ts (необовʼязково)
  text: `Перший рядок
другий рядок

нова строфа після порожнього рядка`,
},
```
Текст відображається рівно так, як записаний: кожен рядок — окремий рядок вірша, порожній рядок — нова строфа. Сторінка, номер, навігація «попередній / наступний», карта сайту і SEO створюються автоматично.

### Замінити фотографії
Усі фото — особисті знімки автора в `public/photos/` (чотири оригінали + кадрування-деталі). Покладіть власні фото у `public/photos/` і замініть `src` у `content/photos.ts`, напр. `src: '/photos/portrait.jpg'`. Обробка (ч/б, зерно, віньєтка) застосовується автоматично до всіх фото. Портрет на сторінці «Про автора» — ключ `authorPortrait`.

### Біографія, пошта, Instagram
`content/site.ts` — замініть заглушки та встановіть `placeholder: false`, щоб прибрати підказку на сторінці «Про автора». Там же — `url` сайту (для SEO), якщо підключите власний домен.

## Логотип

**БIЛОKhA** — типографічний знак, а не шрифт і не рукопис. Літери Б Л О K h A взяті як контури з Noto Serif Display Medium з ручним трекінгом; латинська «I» замінена на власний елемент — тонку бордову вертикаль, що виходить за межі рядка (як закладка в книжці чи цезура у вірші). Це головна впізнавана деталь; разом з «Б» вона утворює монограму для іконки.

| Файл (`brand/`, також `public/brand/`) | Призначення |
|---|---|
| `bilokha-wordmark.svg` | основний знак: графіт `#252525` + бордо `#861B24` |
| `bilokha-wordmark-mono.svg` | одноколірний |
| `bilokha-wordmark-light.svg` | для темного тла / фото |
| `bilokha-monogram.svg` | монограма «Б|» |
| `bilokha-favicon.svg`, `bilokha-avatar.svg`, `bilokha-avatar-1080.png` | іконка сайту, аватар для соцмереж |
| `bilokha-wordmark.png` | растрова версія 2400px |

Знак генерується скриптом `brand/tools/wordmark.mjs` (трекінг, товщина і висота вертикалі — на початку файла):

```bash
npm run brand     # оновлює brand/, public/brand/, іконки та lib/wordmark.ts
```

## Деплой (Vercel)

Репозиторій підключено до Vercel: **кожен push у гілку `main` автоматично публікує нову версію сайту.** Pull request-и отримують окремі превʼю-адреси.

Налаштування збірки стандартні для Next.js (Vercel визначає їх сам): build — `next build`, змінні середовища не потрібні.

Щоб оновити сайт: змініть файл (можна прямо в GitHub через веб-редактор) → Commit to `main` → за хвилину зміни на сайті.
